## Magento 2 modules for Hyvä, built for a store we run ourselves

Over the years we built online stores for several companies we worked for, and we kept hitting the same wall: the extension that almost fits.

When our publishing house needed proper author pages (one book with several authors, one author with many books), we asked one of the best-known Magento extension vendors for a module. What came back was a shop-by-brand module, adapted, with a multiselect attribute standing in for authors.

So we wrote our own many-to-many module. Then the next one, and the one after that. Our store grew module by module, each one tested on real orders and improved because we rely on it every day in production. The modules here are those, packaged for other stores.

### Free and open source

| Module | What it does | Install |
|---|---|---|
| [Blog](https://github.com/SlovaTechModules/module-blog) | A free blog for Hyvä that writes like WordPress | `composer require slova/module-blog` |
| [Cookie Consent](https://github.com/SlovaTechModules/module-cookie-consent) | A free GDPR cookie banner for Hyvä | `composer require slova/module-cookie-consent` |
| [Hyvä ElasticSuite Compat](https://github.com/SlovaTechModules/module-hyva-elasticsuite-compat) | Category swatches back on Hyvä 1.5 with ElasticSuite | `composer require slova/module-hyva-elasticsuite-compat` |

MIT licence, on [Packagist](https://packagist.org/packages/slova/). Found a bug? Open an issue on the module's repository.
